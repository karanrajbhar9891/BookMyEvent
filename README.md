# 🎟️ BookMyEvent

**BookMyEvent** is a full-stack event booking platform where users can discover events, view event details, securely authenticate using OTP verification, book event tickets, and manage their bookings.

The application is built using the **MERN stack** with JWT authentication, MongoDB, Resend email services, and a responsive React frontend.

---

## 📌 Project Overview

BookMyEvent provides a complete event-booking experience for both **users and administrators**.

Users can:

* Create an account
* Verify their email using OTP
* Login securely
* Browse available events
* Search and filter events
* View complete event details
* Book event tickets
* Verify bookings using OTP
* Receive booking confirmation emails
* View their bookings
* Cancel bookings

Administrators can:

* Access protected admin functionality
* Manage events
* Manage bookings
* View booking information
* Control event-related data

# 🔐 2. OTP Verification

BookMyEvent uses OTP verification for important user actions.

A secure **6-digit OTP** is generated by the backend.

Example:

```text
483921
```

The OTP is sent to the user's email through **Resend**.

OTP records contain information such as:

* Email
* OTP
* Action
* Creation time
* Expiration information

Different actions can use different OTP purposes.

Example:

```text
registration
event-booking
```

This prevents an OTP generated for one purpose from being incorrectly used for another purpose.

---

# 🔑 3. JWT Authentication

After successful login, the backend generates a JWT token.

The token is used to authenticate protected API requests.

Authentication flow:

```text
User Login
    ↓
Credentials validated
    ↓
JWT generated
    ↓
Token sent to frontend
    ↓
Frontend stores authentication state
    ↓
Token sent with protected requests
    ↓
Backend verifies JWT
    ↓
Access granted
```

Protected functionality includes:

* User bookings
* Booking OTP
* Booking confirmation
* Admin functionality

# 🗄️ Database

BookMyEvent uses **MongoDB** with **Mongoose**.

Main collections/models include:

```text
User
Event
Booking
OTP
```

---

## 👤 User Model

The User model stores information such as:

```text
name
email
password
role
```

The password should be stored securely using password hashing rather than plain text.

---

## 🎫 Event Model

The Event model contains:

```text
title
description
date
location
ticketPrice
capacity
category
totalSeats
availableSeats
imageUrl
createdBy
```

`createdBy` references the user/admin who created the event.

---

## 🎟️ Booking Model

The Booking model connects users with events.

Conceptually:

```text
User
  │
  └──── Booking ──── Event
```

A booking contains references to:

```text
userId
eventId
```

along with booking-related information.

---

## 🔢 OTP Model

The OTP model manages temporary verification codes.

It stores information such as:

```text
email
otp
action
createdAt
```

The `action` field ensures OTPs are associated with the correct operation.

Example:

```text
event-booking
```

# 🔒 Security

BookMyEvent implements several security mechanisms:

### JWT Authentication

Protects private API routes.

### Password Hashing

Passwords should never be stored as plain text.

### OTP Verification

Adds an additional verification layer for registration and booking.

### Role-Based Authorization

Admin resources are protected from normal users.

### Environment Variables

Sensitive configuration is stored outside source code.

### CORS

Controls communication between frontend and backend applications.
